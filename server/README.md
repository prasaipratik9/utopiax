# UtopiaX API (Week 2 starter)

Light Express scaffold — enough to show backend work started, not a full CMS yet.

## Endpoints

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/health` | Health check |
| GET | `/api/content` | Read `client/src/data/content.json` |

## Run

From repo root:

```bash
npm install
npm run dev:server
```

API: http://localhost:4000
